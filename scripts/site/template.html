Think Smart – Move Fast – Conquer the Maze

Robot Micromouse STM32 tự dò mê cung 16×16 (ô 180 mm lọt lòng, tường 12 mm, bước ô 192 mm) và chạy về 4 ô đích trung tâm nhanh nhất có thể. Trang này gộp toàn bộ tài liệu của project cho cả đội.

Hình 1 trong thể lệ, số hóa tự động từ PDF. Robot mô phỏng chạy bằng đúng thuật toán trong firmware.

⚠️ Code đã được kiểm chứng bằng biên dịch và mô phỏng, chưa chạy trên robot thật của đội. Phải lắp ráp và calib theo tài liệu trước khi thi.

Bấm MODE để chọn (LED nháy N lần = chế độ N), GO để bắt đầu, vẫy tay trước cảm biến trước để xuất phát. Bấm GO khi đang chạy để dừng khẩn.

Bắt đầu nhanh trên máy tính

Cài công cụ (một lần):

python -m pip install platformio ziglang numpy pillow

Test thuật toán (phải ra KET QUA: OK):

powershell -ExecutionPolicy Bypass -File scripts/build_host.ps1

Xem hình robot chạy trên mê cung BTC:

build/test_speedrun.exe --svg build/btc.svg mazes/mysterious_maze_2026.txt 45

Build và nạp firmware (BlackPill F411 qua ST-Link):

python -m platformio run -t upload

Phần cứng: STM32F411 BlackPill · 2 × N20 6V 1:20 có encoder · TB6612FNG · 4 cặp IR 940 nm · LiPo 2S · thân ≤ 100 mm, ≤ 120 g. License GPL-3.0.
